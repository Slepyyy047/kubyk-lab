# Перевірка результату

- `npm run build`: успішна production-збірка; строгий TypeScript, включно з перевіркою невикористаних змінних і параметрів.
- `npm test`: 23 тести, 5 файлів; перемішані стани, 3 довгі відтворювані перемішування, неможливі стани, усі напрями 3D-рухів, передумови навчальних прикладів, localStorage.
- Повна процедура перестановки верхніх ребер перевірена на всіх 24 перестановках із коректною парністю кутів.
- Завершення орієнтації кутів перевірене на всіх 27 можливих комбінаціях поворотів верхніх кутів із сумою, кратною трьом.
- 5 браузерних сценаріїв перевірені у зібраному застосунку: розв’язувач і кожен рух до завершення, пауза/назад/оновлення; порожній/неможливий/складений стан; навігація/усі навчальні демонстрації/мобільне введення; режим без WebGL; reduced motion. Два тестові локатори уточнено й відповідні сценарії повторно пройшли.
- Аудит встановлених залежностей після вилучення невикористовуваного upstream npm: 0 відомих вразливостей.

Знімки: `home-desktop.png`, `home-mobile.png`, `solution-desktop.png`, `lesson-desktop.png`, `lesson-mobile.png`.
