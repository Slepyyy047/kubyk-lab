# Кубик

Український застосунок на React, TypeScript і Vite. П’ять адрес: `/` — інтерактивна головна, `/play` — ручне складання 2×2, 3×3 і 4×4, `/solve` — розв’язувач фізичного 3×3, `/lessons` — курс, `/about` — історія й будова.

## Запуск

Потрібен Node.js 22.12 або новіший (перевірено на Node.js 24).

```sh
npm ci
npm run dev
```

Відкрийте адресу, надруковану Vite, зазвичай http://localhost:5173. Збірка для публікації: `npm run build`; перевірка зібраної версії: `npm run preview`. Готові файли — у `dist/`. На статичному хостингу потрібне перенаправлення невідомих адрес на `index.html` для прямих переходів до `/about` та `/lessons`.

## Як користуватися

На головній можна повертати шари й розсувати деталі для огляду. На `/play` оберіть 2×2, 3×3 або 4×4 й натисніть «Перемішати кубик». Потягніть наліпку вздовж грані для повороту шару; натискання без перетягування обертає всю грань. Порожній простір і права кнопка миші керують камерою. Клавіші U D L R F B повертають грані, Shift змінює напрямок, Alt на 4×4 обирає внутрішній шар, стрілки керують оглядом. Додаткові кнопки доступні в «Керування без жестів». Гра кожного розміру зберігається окремо, після завершення повороту.

Для фізичного кубика відкрийте `/solve`:

1. Спочатку завантажено позначений перемішаний приклад. Для свого кубика натисніть «Очистити»: залишаться шість центрів, решта клітинок стануть порожніми.
2. Зафіксуйте передню F й верхню U грані; відкрийте «Як тримати кубик». Наліпки кожної грані йдуть зліва направо та зверху вниз при погляді прямо на неї. Для іншої схеми кольорів увімкніть редагування центрів.
3. Оберіть колір і натискайте клітинки. Клавіші 1–6 на клітинках розгортки змінюють активний колір; Enter або пробіл фарбує клітинку. На телефоні є збільшені клітинки окремої грані.
4. Натисніть «Знайти розв’язання». Відтворюйте кроки, змінюйте швидкість, оглядайте кубик перетягуванням або кнопками камер. Напрямок повороту завжди визначається при погляді прямо на відповідну грань.

## Реалізовано

- Перевірка заповнення, кількості кожного кольору, унікальності центрів, набору й повторів деталей, дзеркальних кутів, суми орієнтацій ребер і кутів, парності перестановок.
- Справжній двофазний розв’язувач Коцемби, що працює у Web Worker. Результат повторно перевіряється застосуванням усіх виданих рухів.
- 3D-кубик із геометрією URFDLB, поворотами конкретних шарів, зворотними та подвійними рухами, паузою після поточного повороту й переходами між станами.
- Збереження введених кольорів, розв’язання, завершеного кроку й швидкості в `localStorage`. Відновлені розв’язання перевіряються; зіпсовані записи ігноруються.
- Шість уроків із початковими умовами, поясненнями, алгоритмами, прикладами й помилками. Приклади конкретних випадків; уроки не підміняють розв’язання довільного стану.
- Мобільний інтерфейс, клавіатурне керування, видимий фокус, перехід до основного вмісту, зменшення анімацій і кольорова розгортка при недоступному WebGL.

## Перевірки

```sh
npm test
npm run typecheck
npm run build
```

`npm run test:e2e` перевіряє сайт у браузері, коли dev-сервер працює на порту 5173. У Windows автоматично використовується встановлений Chrome. На іншій платформі встановіть Chromium командою `npx playwright install chromium` або задайте шлях змінною `PLAYWRIGHT_CHROME_PATH`. Змінна `TEST_BASE_URL` дозволяє перевірити іншу адресу, зокрема production-preview на порту 4173. Знімки екрана з перевірок зберігаються в `outputs/`.

Тести перевіряють перемішані й неможливі стани, складений кубик, усі напрями 3D-поворотів, результати навчальних демонстрацій, збереження, відтворення вперед/назад, паузу, навігацію, мобільне введення, reduced motion і режим без WebGL.

## Межі

Автоматичний розв’язувач підтримує звичайний 3×3 із шістьма кольорами; ручна гра — 2×2, 3×3 і 4×4. Введення ручне, розпізнавання камерою немає. Розв’язання не гарантує мінімальної кількості рухів. Перший пошук витрачає кілька секунд на таблиці. Локальні записи прив’язані до браузера й адреси сайту та видаляються під час очищення даних. Без WebGL залишається робоча розгортка, але немає об’ємної анімації. Використано системний шрифт без зовнішніх завантажень. Сайт підготовлений локально; публічне розгортання не виконане.

Перевірка після редизайну: TypeScript проходить; математика рухів входить до 29 модульних тестів, які пройшли у середовищі з дозволеним запуском службових процесів. У браузері перевірено збереження, зворотні повороти 2×2 та внутрішнього шару 4×4, перемішування, жести, мобільне меню й уроки. Додано сценарії `e2e/play.spec.ts`. Повторний запуск повної збірки й Playwright у поточному обмеженому середовищі зупиняється до виконання через `spawn EPERM`; запускайте звичайні команди вище в локальному терміналі. Старий `dist/` не є збіркою нового дизайну.
